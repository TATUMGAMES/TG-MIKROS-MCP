# Examples

Response patterns and integration examples for MIKROS MCP.

**Convention:** All sample payloads, JSON blocks, and illustrative URLs in this folder use the **production** MCP environment:

- MCP endpoint: `https://tg-api-new.uc.r.appspot.com/mcp`
- Website auth: `https://developer.tatumgames.com`

Local and staging URLs: [ENVIRONMENTS.md](../ENVIRONMENTS.md).

| File | Description |
|------|-------------|
| [auth-required.md](./auth-required.md) | What to do when MCP returns `AUTH_REQUIRED` |
| [create-project-success.md](./create-project-success.md) | Expected flow after project creation |
| [recommend-events-output.md](./recommend-events-output.md) | How to present event recommendations |
| [campaign-draft.md](./campaign-draft.md) | Marketing campaign draft pattern |

These examples are for **AI assistants** and **documentation maintainers**. They are not executable scripts.
